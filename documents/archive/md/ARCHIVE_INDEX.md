## Why archived

- Original proposals/master notes: unsupported performance and collision claims, broader scope than the current hypothesis.
- Five-/six-way pilot reports: overclaimed causal mechanisms, authentic-model provenance, sequence counts and validation; see current audit.
- Remediation report: useful history but incorrectly marks several benchmark/renderer/training issues resolved.
- Earlier novelty note and plan: exploratory or superseded; planned Schur solver was not actually implemented.
- Framework setup: claims an installed research.py coordinator; no such repository file was found. Current contract uses agy directly.
- Historical state snapshots: original README, RESEARCH and note registries retained before correction.
- Older archived walkthroughs remain under notes/archive/ within this archive to preserve their original grouping.
